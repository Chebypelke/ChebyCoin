# ChebyCoin

Экспериментальный проект криптовалюты, написанный на C++.

## Возможности

- ChebyHash32|64|128
- API для хэширования строк
- 128-битный тип Hash128
- Avalanche-тестирование хэшей
- ChebyChain
- Структура блока
- Genesis Block
- Связывание блоков через предыдущий хэш
- Проверка целостности блокчейна

## ChebyHash

ChebyHash — экспериментальный алгоритм хэширования, разработанный для ChebyCoin.

Поддерживаются 32-, 64- и 128-битные версии.

ChebyHash128 использует собственную структуру Hash128, состоящую из двух 64-битных значений: high и low.

128-битные операции реализованы поверх двух 64-битных значений.

### Avalanche Effect

Хэши тестируются с помощью avalanche-теста.

Тест изменяет один бит входных данных и измеряет, сколько битов выходного хэша изменилось.

| Алгоритм     | Размер хэша | Среднее количество изменившихся битов |
| ------------ | ----------- | ------------------------------------- |
| ChebyHash32  | 32 бита     | ~16                                    |
| ChebyHash64  | 64 бита     | ~32                                    |
| ChebyHash128 | 128 бит     | 63.979                                 |

При идеальном avalanche effect изменение одного входного бита приводит к изменению примерно половины битов выходного хэша.

ChebyHash128 был протестирован на 500 000 случайных входах.

## ChebyChain

ChebyChain — экспериментальная реализация блокчейна для ChebyCoin.

Каждый блок содержит информацию о предыдущем блоке и собственный хэш.

### Реализовано

- Структура блока
- Genesis Block
- Контейнер блокчейна
- Связывание блоков через предыдущий хэш
- Автоматический расчёт хэша блока
- Проверка целостности цепочки
- API доступа к блокам
- Получение количества блоков

## Тестеры

Тестеры позволяют экспериментировать с реализованными компонентами ChebyCoin.

### ChebyHash Tester

- Генерация случайных строк
- Тестирование хэширования
- Avalanche-тестирование
- Измерение среднего количества изменившихся битов
- Измерение времени выполнения

### ChebyChain Tester

- Создание новых блоков
- Просмотр количества блоков
- Просмотр блоков по индексу
- Отображение хэшей в десятичном и шестнадцатеричном формате
- Проверка целостности блокчейна
- Консольный интерфейс

## Сборка

1. Клонируйте репозиторий:

```bash
    git clone git@github.com:Chebypelke/ChebyCoin.git
    cd ChebyCoin
```

2. Соберите проект с помощью CMake:

```bash
    cmake -S . -B build
    cmake --build build
```

## Отказ от ответственности

ChebyCoin — экспериментальный образовательный проект.

ChebyHash и ChebyChain не предназначены для использования в реальных финансовых или криптографических системах.

Проект создаётся в образовательных целях для изучения C++, алгоритмов хэширования, структур данных и принципов работы блокчейна.
