# ChebyCoin

Экспериментальный проект криптовалюты и блокчейна, написанный на C++.

Проект создаётся в образовательных целях для изучения C++, алгоритмов хэширования, 128-битной арифметики, цифровых подписей, архитектуры блокчейна и принципов безопасного программирования.

- Собственный 128-битный тип Hash128

- Проверка цифровых подписей

## ChebyHash

ChebyHash — экспериментальный алгоритм хэширования, разработанный для ChebyCoin.

Поддерживаются 32-, 64- и 128-битные версии.

ChebyHash128 использует собственную структуру Hash128, состоящую из двух 64-битных значений:

- high
- low

128-битная арифметика реализована поверх этих двух 64-битных значений.

### Операции Hash128

ChebyHash128 поддерживает операции:

- Сложение
- Вычитание
- XOR
- Сравнение
- Умножение
- Деление
- Остаток от деления
- Битовые сдвиги
- Битовые вращения
- Модульное сложение
- Модульное умножение

Эти операции используются компонентами более высокого уровня ChebyCoin.

### Avalanche Effect

Хэши тестируются с помощью avalanche-теста.

Тест изменяет один бит входных данных и измеряет, сколько битов выходного хэша изменилось.

| Алгоритм     | Размер хэша | Среднее количество изменившихся битов |
| ------------ | ----------- | ------------------------------------- |
| ChebyHash32  | 32 бита     | ~16                                   |
| ChebyHash64  | 64 бита     | ~32                                   |
| ChebyHash128 | 128 бит     | 63.979                                |

При идеальном avalanche effect изменение одного входного бита приводит к изменению примерно половины битов выходного хэша.

ChebyHash128 был протестирован на 500 000 случайных входах.

## ChebyChain

ChebyChain — экспериментальная реализация блокчейна для ChebyCoin.

Каждый блок содержит информацию о предыдущем блоке и собственный хэш.

### Реализовано

- Структура блока
- Genesis Block
- Контейнер блокчейна
- Связывание блоков через предыдущие хэши
- Автоматический расчёт хэша блока
- Проверка целостности блокчейна
- API доступа к блокам
- Получение количества блоков

## ChebySignature

ChebySignature — экспериментальный компонент цифровых подписей, построенный поверх собственной 128-битной арифметики Hash128.

В текущей версии реализована учебная RSA-подобная схема цифровой подписи.

### Реализовано

- Генерация RSA-подобной пары ключей
- Публичный ключ
- Приватный ключ
- Вычисление модульного обратного элемента
- Модульное возведение в степень
- Создание цифровой подписи
- Проверка цифровой подписи
- Тестирование проверки подписи

В текущей реализации используется публичная экспонента e = 65537.

Приватная экспонента вычисляется как обратный элемент e по модулю функции Эйлера:

d = e⁻¹ mod φ

Создание подписи выполняется по формуле:

signature = hash^d mod n

Проверка подписи выполняется по формуле:

verified = signature^e mod n

Реализация успешно проверяет, что восстановленный хэш совпадает с исходным.

### Важно

ChebySignature является учебной реализацией.

Она не является криптографически безопасной и не предназначена для использования в реальных системах аутентификации, цифровых подписей, криптовалютах, финансовых системах или защищённых коммуникациях.

Текущая реализация не использует промышленные криптографические стандарты, такие как RSA-PSS, PKCS#1 v1.5, безопасное padding-кодирование или криптографически стойкую генерацию ключей.

## Тестеры

Тестеры позволяют экспериментировать с реализованными компонентами ChebyCoin.

### ChebyHash32|64|128 Tester

- Генерация случайных строк
- Тестирование хэширования
- Avalanche-тестирование
- Измерение среднего количества изменившихся битов
- Измерение времени выполнения

### ChebyChain Tester

- Создание новых блоков
- Просмотр количества блоков
- Просмотр блоков по индексу
- Отображение хэшей в десятичном и HEX формате
- Проверка целостности блокчейна
- Консольный интерфейс

### ChebySignature Tester

- Генерация RSA-подобной пары ключей
- Подписание хэша сообщения
- Проверка цифровой подписи
- Сравнение исходного и восстановленного хэша
- Вывод результата PASS/FAIL

## Сборка

1. Клонируйте репозиторий:

```bash
git clone git@github.com:Chebypelke/ChebyCoin.git
cd ChebyCoin
```

2. Соберите проект с помощью CMake:

```bash
cmake -S . -B build
cmake --build build
```
