# ChebyCoin

Экспериментальный проект криптовалюты, написанный на C++.

## Возможности

- ChebyHash32
- ChebyHash64
- API для хэширования строк
- Тестирование avalanche effect для обеих версий
- Утилиты для генерации случайных строк

## ChebyHash

ChebyHash — экспериментальный алгоритм хэширования, разработанный для ChebyCoin.

Обе версии, 32-битная и 64-битная, были протестированы с помощью avalanche-теста. Тест изменяет один бит входных данных и измеряет, сколько битов выходного хэша изменилось.

### Результаты тестирования

| Алгоритм   | Размер хэша | Среднее количество изменившихся битов |
| ----------- | ----------- | ------------------------------------- |
| ChebyHash32 | 32 бита     | ~16                                   |
| ChebyHash64 | 64 бита     | ~32                                   |

При идеальном avalanche effect изменение одного входного бита приводит к изменению примерно половины битов выходного хэша.

## Сборка

Клонируйте репозиторий:
```bash
    git clone git@github.com:Chebypelke/ChebyCoin.git
    cd ChebyCoin
```

Соберите проект с помощью CMake:
```bash
    cmake -S . -B build
    cmake --build build
```
